A video editor you edit together with Claude. Pick the file for your computer below (under **Assets**).

| Computer | File |
| --- | --- |
| Windows 10 / 11 | `Jimmy-The-Editor-Setup-<version>.exe` (installer), or `…-win-x64.zip` (portable: unzip and run) |
| Mac with Apple silicon (M1 and later) | `Jimmy-The-Editor-<version>-mac-arm64.dmg` |
| Mac with an Intel processor | `Jimmy-The-Editor-<version>-mac-x64.dmg` |

Not sure which Mac you have? Apple menu › **About This Mac**: "Chip: Apple M…" means Apple silicon.

**Windows:** run the installer. The app isn't signed, so Windows may show "Windows protected your PC": click
**More info › Run anyway**. Jimmy then opens from the Start menu.

**Mac:** open the dmg and drag **Jimmy - The Editor** to **Applications**. The app isn't notarized by Apple, so the
first time you open it macOS says it can't check it. Click **Done** (not Move to Trash), then go to **System Settings ›
Privacy & Security**, scroll down and click **Open Anyway** next to Jimmy, and confirm. After that it opens normally.

**Claude:** for the built-in Claude chats, install [Claude Code](https://claude.com/claude-code) and sign in from
Jimmy's Settings › Accounts. The editor itself works without it.
